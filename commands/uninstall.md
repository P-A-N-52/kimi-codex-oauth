---
description: 预览并清理本插件管理的配置，安全停止代理后移除插件
---

执行用户请求的插件卸载：

1. 记录当前插件实际目录、端口和路径环境变量。若默认模型正在使用 chatgpt/*，先告知需要切换到已有的其他可用模型；不得猜测或删除个人模型设置。
2. 运行插件目录中的 bin/uninstall.mjs --dry-run，检查列出的待删除段落与因引用而保留的段落。
3. 用户请求卸载已授权执行清理；运行同一脚本不带 --dry-run。脚本会核对代理实例身份并停止，备份配置，通过校验后清理符合条件的受管段落。脚本失败时报告原因，不绕过校验，不删除登录缓存或批量杀进程。
4. 随后让用户立即在 Kimi Code 执行 /plugins remove kimi-codex-oauth 和 /reload，再开启新会话。若仅运行清理而插件仍启用，下次会话会重新启动代理。
5. 报告清理结果、保留项、备份路径、代理是否已停止，以及是否完成 Kimi 中的插件移除。不得将脚本清理等同于已经从插件管理器移除。

v0.1.0 的旧代理没有实例状态，按 README 核对监听端口对应的具体脚本路径后再停止。保留 auth.json、个人配置、日志和备份。
